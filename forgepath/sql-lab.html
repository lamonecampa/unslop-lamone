Contoh data awal

Database memiliki tabel mahasiswa dan nilai. Coba SELECT, WHERE, ORDER BY, GROUP BY, JOIN, INSERT, UPDATE, dan DELETE.

mahasiswa(id, nama, kelas, nilai)
nilai(id, mahasiswa_id, mata_kuliah, nilai)

Urutan latihan

  1. Tampilkan semua data.
  2. Filter nilai di atas 80.
  3. Urutkan nilai dari tertinggi.
  4. Hitung rata-rata per kelas.
  5. Gabungkan mahasiswa dan nilai dengan JOIN.
  6. Tambahkan satu record baru dengan INSERT.

Catatan teknis

Mesin ini menggunakan SQLite, bukan MySQL. Sintaks dasar SQL serupa, tetapi beberapa tipe data, fungsi, dan fitur berbeda. Gunakan MySQL/MariaDB untuk menguji query yang akan dipakai di proyek PHP/Laravel.
