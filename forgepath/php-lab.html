Tulis PHP. Pahami prosesnya.

Gunakan editor untuk menulis dan menyalin kode latihan. Jalankan kode melalui PHP interpreter di komputer sendiri. Halaman statis ini tidak berpura-pura menjadi server PHP.

Penting: PHP berjalan di sisi server. Editor di bawah ini bukan compiler PHP. Untuk menjalankan kode, instal PHP atau paket seperti XAMPP/Laragon, simpan file sebagai index.php, lalu akses melalui server lokal.
LATIHAN.PHPEDITOR KODE

Eksperimen berikutnya

  1. Ubah nilai menjadi 60. Prediksi output sebelum menjalankan.
  2. Ganti nama dan tampilkan kembali.
  3. Buat perulangan for untuk menampilkan angka 1 sampai 5.
  4. Buat function hitungLuas($p, $l) yang mengembalikan luas persegi panjang.

Menjalankan PHP di Windows

  1. Instal XAMPP atau Laragon.
  2. Simpan file di folder web server, misalnya htdocs/latihan.
  3. Jalankan Apache dari control panel.
  4. Buka http://localhost/latihan/.

Alternatif: instal PHP CLI, buka terminal pada folder file, lalu jalankan:

php latihan.php

Konsep yang harus dikuasai

  • Variabel dan tipe data
  • Operator dan percabangan
  • Perulangan dan array
  • Function dan parameter
  • Form GET/POST
  • Validasi dan keamanan input
  • PDO atau MySQLi
